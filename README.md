# 🏠 Peshawar House Rental Finder

A simple Streamlit web app to search and list rental houses in Peshawar — by area, rent range, rooms, and house type.

## Features
- Search & filter houses by village/area, rent, rooms, and type
- View full house details in a card layout
- Add new house listings through a built-in form
- Contact owner directly (phone / WhatsApp)

## Tech Stack
- Python
- Streamlit
- Pandas

## Run Locally
```
pip install -r requirements.txt
streamlit run app.py
```
